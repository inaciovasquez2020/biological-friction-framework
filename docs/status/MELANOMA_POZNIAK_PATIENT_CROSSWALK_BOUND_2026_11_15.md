## New source-grounded facts

- The paper analyzes **23 patients**. Its STAR Methods report **17 anti-PD-1 monotherapy patients in the entire cohort** and **15 in the malignant subset**; the remaining **six** receive nivolumab + ipilimumab (five in malignant subset). The results text describes monotherapy treatment as nivolumab for 17; STAR Methods additionally specify nivolumab or pembrolizumab.
- The paper includes pretreatment (BT) and early on-treatment (OT) samples; 20 patients have matched timepoints, two have BT-only (GC25, GC29) and one OT-only (GC39), with multiple BT/OT biopsies from GC16. Biopsy-count totals are **not** patient counts and cannot be treated as independent observations.
- For unresectable disease, authors define responders as complete or partial remission and nonresponders as **stable disease OR progressive disease**, by RECIST v1.1 best overall response. For some patients subsequently surgically resected after cycle two with curative intent, response is defined using pathological complete response instead. Hence original grouped R/NR is not a valid substitute for the frozen `CR/PR versus PD; exclude SD/mixed/unknown` endpoint.
- Author code confirms that `Response` was recoded from `0` to `NR` and `1` to `R` after a join to a separate clinical workbook. This code alone does not recover individual underlying CR, PR, SD and PD categories, nor necessarily distinguish RECIST and pathological endpoints.
- KU Leuven V8 lists `Entire_TME.rds` (~2.5 GB), `Malignant_cells.rds` (~824.4 MB), `GC_all_immune_sharing.rds` (~945.2 MB), and `Pozniak_README_v6.txt` (2.1 KB; MD5 `0223b9fe806db07797246e6542083c0a`). The small README record was inspected at metadata level; its full text and original Table S1 were **not** obtained in this audit. Large objects were not downloaded.
- Source-data license indicated as CC-BY-NC-SA-4.0. Dataset-use obligations must be honored.

## Mathematical eligibility bound

Let `M` be the set of study patients with a malignant compartment represented, `P` those assigned anti-PD-1 monotherapy, `B` those with eligible pretreatment biopsy, `C` those with both malignant and macrophage CD36 measurable from a matched specimen and reliable annotations, and `E` those with explicit admissible RECIST CR/PR/PD endpoint.

Eligible patients: `A := M ∩ P ∩ B ∩ C ∩ E`.

The original paper reports `|M ∩ P| = 15`. Therefore

```
|A| <= |M ∩ P| = 15.
```

This upper bound does **not** certify any positive number of eligible patients; `|A|=0` remains logically possible with the information reviewed.

**Endpoint nonidentifiability:** If an original binary `NR` group merges SD and PD, there is no function mapping `NR` uniquely back to PD. The same `NR` is generated by SD or PD; this is an elementary many-to-one map. No response-informed imputation may be performed.

If an analysis needs both cell types in the *same patient, same baseline biopsy*, the presence of both compartments in the source study as a whole is insufficient: patient-level intersection must be verified from annotation and sample metadata.

## Decision and resource gate

1. Do not score or fit BFF v2 on these samples: GSE91061 frozen-v2 AUROC 0.4913 is unchanged, and the cell-resolved assay is not proven compatible with frozen Cuffnorm FPKM ECDF references.
2. Obtain the actual clinical Table S1 (or original workbook plus provenance) before processing RDS files.
3. Reconstruct fields `patient_id, specimen_id, BT/OT, drug/regimen, unresectable_vs_resected, RECIST_CR_PR_SD_PD_vs_pathologic, malignant_cell_count, macrophage_cell_count` with citations to original source rows.
4. Exclude SD, pathological-only responses, combo therapy, missing baseline, repeated specimens without a frozen selection rule, and unmatched compartments.
5. Report exact eligible patient count **before** considering GB-scale data transfer or patient-level CD36 estimation. If no admissible records remain, stop the frozen-endpoint validation proposal.
